Sobre o Permanecer+

Objetivo: apoiar a escola na identificação antecipada de sinais associados à baixa permanência e organizar registros de acompanhamento.

Diferencial desta proposta

Enquanto soluções tradicionais podem concentrar-se em dashboards e alertas, o Permanecer+ coloca o plano de atendimento no centro do fluxo: identificar o sinal → registrar a ação → acompanhar a evolução.

Tecnologias

HTML, CSS e JavaScript no frontend; Node.js no backend; SQLite com banco local; API REST para integração.

Observação acadêmica

Os dados apresentados são fictícios e servem apenas para demonstração. O sistema não determina que um estudante abandonará a escola; ele apenas organiza indicadores para apoiar a análise humana.
