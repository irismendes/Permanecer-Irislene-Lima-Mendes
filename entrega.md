# Roteiro de apresentação

1. Apresentar o problema: sinais de risco podem aparecer antes da evasão.
2. Mostrar o dashboard e explicar os indicadores.
3. Demonstrar o cadastro de um estudante.
4. Mostrar como o sinal é calculado.
5. Registrar um atendimento.
6. Explicar a arquitetura frontend → API → SQLite.
7. Destacar que os dados são fictícios e que a ferramenta apoia a decisão humana.
