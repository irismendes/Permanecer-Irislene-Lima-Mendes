# Casos de Uso — Permanecer+

**Ator principal:** Gestor/equipe escolar.

## UC01 — Cadastrar estudante
Informar dados → validar → salvar → atualizar lista.

## UC02 — Consultar dashboard
Acessar painel → API consulta banco → sistema calcula indicadores → exibe resumo.

## UC03 — Consultar estudantes
Acessar estudantes → consultar registros → visualizar frequência, média e nível.

## UC04 — Registrar atendimento
Selecionar estudante → informar data, tipo e descrição → salvar.

## UC05 — Consultar atendimentos
Acessar histórico → consultar banco → exibir registros.

## UC06 — Identificar necessidade de acompanhamento
Sistema analisa frequência e média → aplica regras → apresenta nível de acompanhamento.
